# Literature and relationship to CSDE

**Reading rule:** These references motivate parts of a proposed methodology. None demonstrates that CSDE as a whole improves research outcomes. Links are to primary papers or canonical publication records; check metadata and results before formal citation.

| Line of work | Reference | Connection / distinction |
| --- | --- | --- |
| Compositional learning | [Okawa et al., *Compositional Abilities Emerge Multiplicatively*](https://arxiv.org/abs/2310.09336) | Multiplicative dependence in a synthetic learning setting; not preservation of unrealized research ideas. |
| Hidden capabilities | [Park et al., *Emergence of Hidden Capabilities*](https://arxiv.org/abs/2406.19370) | Measurement and elicitation of capabilities inside existing systems; not missing substrates. |
| Task arithmetic | [Ilharco et al., *Editing Models with Task Arithmetic*](https://arxiv.org/abs/2212.04089) | Recombining weight-space updates; does not alone establish general superadditive emergence. |
| Model merging boundary | [*On Emergent Capabilities and Model Merging*](https://arxiv.org/abs/2609.24504) | Potential negative/boundary result for naive combination; validate detailed conditions. |
| Automated capability search | [Lu et al., *Automated Capability Discovery via Foundation Model Self-Exploration*](https://arxiv.org/abs/2502.07577) | Automated task generation and archival; distinct from retaining unimplemented ideas. |
| Quality-diversity | [Mouret & Clune, *Illuminating search spaces by mapping elites*](https://arxiv.org/abs/1504.04909) | Diverse candidate archive as a strong baseline, not a strawman. |
| Open-ended composition | [*A Compositional Framework for Open-ended Intelligence*](https://arxiv.org/abs/2606.15386) | Search through compositional primitives; investigate whether primitive availability changes over time. |
| AI-guided evolutionary research | [Romera-Paredes et al., *Mathematical discoveries from program search with large language models*](https://www.nature.com/articles/s41586-023-06924-6) | FunSearch: programs evolved with evaluator feedback and retained diversity. |
| Scientific recombination | [Simonton, *Scientific Creativity as a Combinatorial Process*](https://doi.org/10.3389/fpsyg.2021.721104) | Theory of creative recombination, not direct experimental support for H2. |
| Experimental incentives | [Rzhetsky et al., *Choosing experiments to accelerate collective discovery*](https://doi.org/10.1073/pnas.1509757112) | Individual versus collective experiment-selection incentives. |
| Delayed recognition | [Ke et al., *Defining and identifying Sleeping Beauties in science*](https://doi.org/10.1073/pnas.1424329112) | Recognition delay motivates revisiting literature; it does not prove a capability-substrate mechanism. |
| Recursive reuse | [*Recursive Formation and First-Class Reuse of Compositional Capabilities*](https://arxiv.org/abs/2610.19414) | Persistent reusable capability operators; inspect overlap before asserting novelty. |

## Gaps worth investigating

1. **Explicit missing-dependency records** for ideas that cannot presently be implemented or tested.
2. **Reassessment triggers** based on changed primitives or available substrates.
3. **Evidence-preserving failures:** distinguish an idea falsified under adequate conditions from one blocked by infrastructure.
4. **Strong H2 comparisons:** dynamic-primitive environments with equal budgets and quality-diversity controls.

Please suggest corrections with exact relevant passages and limitations rather than unqualified "supports our hypothesis" labels.
