# Contributing

Welcome: corrections, failed replications, boundary cases, prior-work connections, new controlled experiments and explicit negative results.

1. **Separate evidence from conjecture.** Mark hypothetical examples and provide provenance for empirical claims.
2. **Search existing work first.** Prefer precise comparisons over novelty claims.
3. **For new ideas**, follow [ideas/SCHEMA.md](ideas/SCHEMA.md) and state missing dependencies and tests.
4. **For experiments**, document controls, budgets including archive overhead, data/evaluation leakage checks, seeds, preregistered metrics, and negative outcomes.
5. **For literature**, link primary sources and say both what the work establishes and what it does *not* establish for CSDE.
6. **For safety**, do not contribute secrets, personal datasets, exploit workflows, or automated deployment to real systems. Begin with benign synthetic experiments.
7. **For AI-assisted contributions**, verify citations and disclose substantial assistance; review all generated code and claims.

This project is exploratory. Constructive counterexamples are as valuable as supportive results.
